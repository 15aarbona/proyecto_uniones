# Modelo autorregresivo

Incluye los archivos completos de `core` y un notebook de entrenamiento.

1. Copia `core/` dentro de tu aplicación.
2. Ajusta `DATA_PATH` en el notebook.
3. Reinicia el kernel.
4. Ejecuta las celdas en orden.

El ruido `noise_std=0.05` está expresado en escala estandarizada, no en milímetros.
